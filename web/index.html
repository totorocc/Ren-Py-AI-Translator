Step 3

Characters & pronouns

Languages like Vietnamese and Japanese pick pronouns from relationships. A wife must address her husband as anh/em, never the flat bạn/tôi. Build a character guide so dialogue stays in character across the whole game.

Step 4

API & model

This tool calls any OpenAI-compatible endpoint. 9Router runs locally and exposes one by default. Pick whichever model you configured in 9Router.

Tuning

Larger batches are faster but riskier; lower the temperature for literal output.

The game's own font usually has no Vietnamese glyphs, so accented letters vanish (cằm shows as c m). The font you pick is copied into the game and used only for this language. Check its licence before sharing the translation.
